# Botyara API

Бэкенд для сайта botyara.ru — та же AI-логика, что в Telegram-боте (Groq: чат, перевод,
промпты для Suno/картинок/видео, обложки треков), но как обычное веб-API.

## Файлы

- `main.py` — сам API-сервер (FastAPI), список эндпоинтов
- `ai_service.py` — вся логика обращения к Groq (переиспользуемая, без привязки к Telegram)
- `requirements.txt` — зависимости
- `.env.example` — пример файла с переменными окружения

## Локальный запуск (для проверки перед деплоем)

```bash
pip install -r requirements.txt
```

Создай файл `.env` рядом с `main.py` (скопируй `.env.example` и впиши свой ключ):
```
GROQ_API_KEY=твой_настоящий_ключ
```

Запусти:
```bash
uvicorn main:app --reload
```

Открой в браузере: http://127.0.0.1:8000/docs — там будет автоматическая документация
со всеми эндпоинтами, можно сразу потыкать их прямо из браузера.

## Эндпоинты

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/health` | Проверка, что сервис работает |
| POST | `/api/chat` | Обычный чат (шлёшь всю историю диалога) |
| POST | `/api/translate` | Перевод текста |
| GET | `/api/prompt/topics` | Список тем промптов и версий для кнопок |
| POST | `/api/prompt` | Диалог по составлению промпта (Suno/Картинка/Видео) |
| POST | `/api/prompt/image-from-photo` | Промпт для правки присланного фото |
| GET | `/api/cover/formats` | Список форматов обложки для кнопок |
| POST | `/api/cover` | Генерация промпта для обложки трека |

## Деплой на Timeweb Cloud App Platform

1. Загрузи этот код в новый репозиторий на GitHub (например `botyara-api`)
2. В Timeweb Cloud → App Platform → "Создать App" → тип **Backend** → **FastAPI** (Python)
3. Подключи созданный репозиторий
4. В настройках приложения добавь переменную окружения `GROQ_API_KEY`
5. Timeweb сам определит команду запуска для FastAPI-приложений; если попросит указать вручную:
   - Команда запуска: `uvicorn main:app --host 0.0.0.0 --port 8000`

## Важно

- Сейчас у API **нет авторизации** и он не подключён к базе данных — это следующий этап
- История переписки, промпты и т.д. пока хранятся только на стороне того, кто вызывает API
  (в будущем — на сайте, у пользователя в браузере или в базе данных после того как добавим авторизацию)
- CORS сейчас открыт для всех источников (`allow_origins=["*"]`) — это нормально для разработки,
  но когда появится домен сайта, нужно будет ограничить до `https://botyara.ru`
